<h1>First Person Shooter AI</h1>

This project was focused on trying to make a robust AI system for a single-player First Person Shooter game. We accomplished this using Unity and Unity's Navigation Package. The AI has the following features:

- A functional state machine that handles and changes the state of the AI depending on the situation such as a level trigger or spotting the player.
- Animations that change depending on the AI actions such as how fast the AI is moving and tracking where the player is.
- A working tracking system where the AI will chase down the player when they spot them.
- Functional ally AI that will help the player in combat.
- A working pathfinding system that allows the AI to roam the level when not in pursuit of the player.
